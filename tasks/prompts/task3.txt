Component Implementation: Embeddable `Badge` UI Component

Problem Description:
Develop a new visual status badge component `Badge` in `rich/badge.py` (and export it in `rich/__init__.py` and `rich.__all__`).
The component must be fully compatible with Rich's layout and rendering pipeline so that it can be printed directly via `console.print(badge)` or embedded seamlessly inside Tables, Panels, Columns, and Trees.

Architectural Standard:
The component must strictly adhere to the internal architectural conventions of this repository (as documented in the project Architecture Decision Records). It must implement the standard streaming render protocol and measurement protocol accepted in the codebase, properly handling standalone and nested layouts without breaking composition or accessing private console state.

Requirements:
1. Create `rich/badge.py`:
   - Class `Badge`:
     ```python
     def __init__(
         self,
         text: str,
         *,
         style: StyleType = "bold white on blue",
         border_style: StyleType = "blue",
         pill: bool = True,
         icon: Optional[str] = None,
     ) -> None:
     ```
   - When `pill=True`, formats the badge with curved pill borders `( ` ... ` )`.
   - When `pill=False`, formats with square borders `[ ` ... ` ]`.
   - If `icon` is provided, includes `icon + " " + text`.
   - Accurately reports cell measurement based on character cell lengths.
2. In `rich/__init__.py`:
   - Expose `Badge` in `__all__` and make it importable from the top-level `rich` package.
3. Verification:
   - Must comply with project architectural standards and render cleanly when printed standalone or nested inside Tables and Panels.
   - All existing tests must continue to pass without regressions.
